# Banking Simulator

The Banking Simulator is a Java-based application that simulates basic banking operations.  
This project is developed to demonstrate core Java concepts and Object-Oriented Programming (OOP) principles through a simple banking system.

---

## Project Description

This application allows users to perform essential banking activities such as creating an account, depositing money, withdrawing money, and checking the account balance.  
It is a beginner-friendly project suitable for academic learning and practice.

---

## Features

- Account creation
- Deposit functionality
- Withdrawal functionality
- Balance inquiry
- Simple and easy-to-understand logic
- Object-Oriented design
